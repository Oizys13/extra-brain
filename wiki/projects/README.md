# wiki/projects/ — Project pages

One page per project or active workstream: what it is, where it stands, and what has been
decided. Intended to be the single place to get up to speed.

**What belongs here**

- A page per project, initiative, or substantial piece of work.
- Status, goals, scope, milestones, and next actions.
- Decisions and their rationale (with dates).
- Links to relevant concepts, people, sources, and journal entries.

**Suggested page skeleton**

```markdown
# Project Name

**Status:** active | paused | done
**Started:** YYYY-MM-DD
**Last reviewed:** YYYY-MM-DD

## Goal
## Current state
## Decisions
## Next actions
## Related
```

**Conventions**

- Filename: lowercase, hyphenated (`project-name.md`).
- Update the review date whenever you touch the page.
- Add the page to `wiki/index.md` and record changes in `wiki/log.md`.
