# journal/ — Daily notes

One note per day. This is where raw daily context lives: what happened, what you worked on,
what you're thinking about, loose ends to follow up on.

**Conventions (recommended)**

- Filename: `YYYY-MM-DD.md` (e.g. `2026-10-28.md`).
- One file per calendar day; append throughout the day.
- Common headings: `## Log`, `## Decisions`, `## Ideas`, `## Follow-ups`.
- Link out generously to `wiki/` pages with `[[...]]`.
- Anything that becomes durable knowledge should be promoted from here into `wiki/`.

Daily notes are yours to write freely. They are not summarized or rewritten unless asked;
the assistant may **add** to a day's note (e.g. a recap) but should not rewrite what you wrote.
