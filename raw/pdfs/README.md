# raw/pdfs/ — General PDFs

PDFs that are not arXiv papers: books, reports, whitepapers, manuals, slide decks, invoices,
scanned documents. Store them untouched.

**What belongs here**

- Books and ebook PDFs you own.
- Reports, whitepapers, standards, documentation.
- Articles saved as PDF, course material, slide decks.
- Scans and other one-off documents.

**Naming convention (recommended)**

`YYYY-<author-or-org>-<short-title>.pdf`

Examples:

- `2019-kahneman-thinking-fast-and-slow.pdf`
- `2026-acme-inc-annual-report.pdf`

If a file has no clear author or date, keep the original filename and note the details in
`wiki/`. Very large libraries are better kept outside the vault — link to them instead.

**Where to export it from**

Whatever the source is: browser **Print → Save as PDF**, publisher/author download links,
or a scanner app. If you downloaded it from a web page, record the URL in a sidecar note or
in the related `wiki/` page so it can be found again.
