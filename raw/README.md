# raw/ — Source documents (read-only)

This folder holds **original source material exactly as it arrived**: exports, downloaded
papers, transcripts, PDFs. Nothing here should be rewritten, summarized, or "cleaned up".

**Rules**

- Treat everything in `raw/` as immutable. Add new files; never edit existing ones.
- If a source needs correcting or annotating, do that on the related page in `wiki/`.
- Keep original filenames when possible so it stays traceable back to the source.
- Every wiki page that draws on a source should link to the file here.

**Subfolders**

| Folder | Contents |
| --- | --- |
| `chatgpt-exports/` | ChatGPT account data exports (conversations) |
| `arxiv-papers/` | Papers downloaded from arXiv |
| `youtube-transcripts/` | Transcripts/captions from YouTube videos |
| `pdfs/` | All other PDFs: books, reports, articles, manuals |
