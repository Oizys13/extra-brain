# raw/arxiv-papers/ — arXiv papers

Papers downloaded from [arXiv](https://arxiv.org) in their original form. Do not rename the
PDF body contents or edit the files; add notes about them in `wiki/` instead.

**What belongs here**

- arXiv PDFs, source archives (`.tar.gz` with LaTeX), and `abs` page snapshots.
- Optional sidecar metadata file per paper (`.md` or `.json`) with title, authors, year,
  arXiv ID, and the URL you downloaded it from.

**Naming convention (recommended)**

`YYYY-<arxiv-id>-<short-slug>.pdf`

Examples:

- `2024-2405.12345-attention-is-all-you-need.pdf`
- `2023-2303.08774-gpt4-technical-report.pdf`

**Where to export it from**

1. Open the paper page at `https://arxiv.org/abs/<id>`.
2. Use **PDF** (right-hand sidebar) or the direct link `https://arxiv.org/pdf/<id>`.
3. Save into this folder using the naming convention above.
4. For the LaTeX source, use **Other formats** → **Source** on the paper page.

Do not paste copyrighted excerpts into wiki pages beyond what you need for commentary.
