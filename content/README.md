# content/ — Content pipeline

Drafts and work-in-progress for things you publish or share: posts, essays, newsletters,
talks, videos, threads.

**Suggested structure**

| Folder | Stage |
| --- | --- |
| `ideas/` | Captured ideas, not yet committed to |
| `drafts/` | Actively being written |
| `published/` | Finished and shipped (kept for reference) |

Create these subfolders when you need them; keep the naming simple.

**Conventions**

- Filename: `YYYY-MM-DD-slug.md` for drafted/published pieces; `slug.md` is fine for ideas.
- Each piece starts with frontmatter or a short header: status, target audience, channel,
  and the `wiki/` pages or `raw/` sources it draws on.
- Move a piece forward rather than duplicating it; keep the history visible.
- Published pieces record the URL and publish date at the top.
